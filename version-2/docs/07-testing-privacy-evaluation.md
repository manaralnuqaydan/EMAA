# المرحلة 7: الاختبارات والأداء والدقة والخصوصية

كل رقم هنا مقاس فعلًا، وكل شي ما انقاس مكتوب عليه **Not Measured**.

## 1) الاختبارات الآلية

| المجموعة | الأمر | النتيجة |
|---|---|---|
| الـ API (بايثون) | `cd model && python -m pytest tests` | 14 ناجح |
| تجهيز نقاط ASL (normalize / mirror) | ضمن نفس الأمر | منها 3 |
| تقسيم الحروف ونوع السؤال (الواجهة) | `npm test` | 4 ناجح |
| TypeScript | `npx tsc --noEmit` | بدون أخطاء |
| البناء | `npm run build` | ناجح |
| لقطات الواجهة (Playwright) | يدوي | عربي وإنجليزي، جوال وشاشة عريضة، بدون أخطاء صفحة |

اختبارات الـ API ما تتصل بالإنترنت أبدًا: المساعد مستبدل بدالة وهمية، وتتأكد من:
- حالة الموديلات في `GET /` تطابق الملفات الموجودة فعلًا.
- المدخلات الغلط ما تطيّح الخادم.
- لغة الإشارة غير المدعومة (مثل `bsl`) ترجع 422.
- الرد الجاهز (بدون اتصال) مكتوب عليه مصدره، وما يعطي الأفاتار كلمات عربية لما تكون لغة الإشارة ASL.

## 3) زمن الاستجابة (مقاس)

مقاس بـ `model/latency.py`: 300 تكرار بعد 20 تكرار تسخين. الجهاز معالج سحابي بـ 4 أنوية وبدون GPU. النتيجة الكاملة في `model/results/latency.json`.

| القياس | المتوسط | الوسيط | p95 |
|---|---|---|---|
| حروف ArSL: الموديل وحده | 1.56ms | 1.41ms | 2.02ms |
| حروف ArSL: الطلب كامل عبر الـ API | 5.56ms | 5.39ms | 6.69ms |
| عبارات ArSL: الموديل وحده | 4.53ms | 4.11ms | 5.90ms |
| عبارات ArSL: الطلب كامل | 9.97ms | 9.15ms | 12.55ms |
| حروف وكلمات ASL | Not Measured | | الموديلات غير مدرّبة |
| المساعد (Claude الحقيقي) | Not Measured | | جربناه بخادم وهمي فقط |
| MediaPipe في المتصفح | Not Measured | | يعتمد على جهاز المستخدم |

- الطلب كامل يُقاس داخل نفس العملية (TestClient)، فما يشمل الشبكة بين المتصفح والخادم.
- ملف `model/README.md` القديم يقول "قرابة 30ms"، والقياس الجديد على هذا الجهاز أقل بكثير. نصحح الرقم في المرحلة 8.

## 5) الخصوصية: وش يطلع من الجهاز

| البيانات | وين تروح | تنحفظ؟ |
|---|---|---|
| فيديو الكاميرا | ما يطلع من المتصفح | لا |
| صورة اليد المقصوصة 64×64 رمادية (حروف ArSL) | خادم إيماء `/predict-image` | لا، تنعالج في الذاكرة فقط |
| نقاط اليد أو الجسم (ArSL عبارات، ASL) | خادم إيماء | لا |
| نص المحادثة مع المساعد | خادم إيماء ثم Claude (Anthropic) | خادم إيماء ما يحفظه، والأخطاء تنسجل بنوعها فقط بدون النص |
| اللغة المختارة وموافقة الكاميرا | `localStorage` في المتصفح | نعم، على جهاز المستخدم فقط |
| حفظ المحادثة | ملف نصي ينزل على جهاز المستخدم بطلبه | على جهازه فقط |

- **تنبيه الموافقة:** يظهر قبل أول تشغيل للكاميرا (`CameraConsent.tsx`). يشرح وش ينرسل، وأن النص يروح لـ Claude، وحدود الترجمة. الموافقة تنحفظ في `emaa.cameraConsent`.
- **تحت خانة المساعد:** سطر يقول إن الرسائل تُرسل لـ Claude وإن المستخدم لا يكتب معلومات حساسة.
- **المفتاح:** مفتاح Claude موجود فقط في `model/.env` على جهاز التشغيل، والملف مستثنى من git.

## 6) الاستخدام المسؤول

- إيماء أداة مساعدة للتواصل اليومي البسيط، **وليست بديلًا عن مترجم لغة إشارة معتمد**، خصوصًا في المواقف الطبية والقانونية والطوارئ. هذا مكتوب في تنبيه الكاميرا.
- الأفاتار يتهجى حروف فقط. ما يقدّم ترجمة للغة الإشارة الكاملة بقواعدها، ونوع الحركة موصوف بصدق في `06-avatar.md`.
- ما نخلط لغات الإشارة: ArSL و ASL منفصلتين في الموديلات وأشكال اليد ورد المساعد.
- يتماشى هذا مع [بيان WFD و WASLI عن الأفاتارات (2018)](https://wfdeaf.org/wp-content/uploads/WFD-and-WASLI-Statement-on-Avatar-FINAL-14032018-Updated-14042018.pdf)، اللي يشدد على:
  - إشراك الصم في التطوير والتقييم.
  - أن الأفاتار ما يحل محل المترجم البشري في التواصل المهم.

  هذا ملخصنا للبيان، وننصح بقراءة النص الأصلي قبل الاقتباس منه في العرض.
- **مطلوب قبل المعرض:** تجربة مع مستخدمين صم سعوديين لتقييم وضوح التهجئة وتعابير الوجه، وتسجيل النتيجة بدل "Not Measured".
