# المرحلة 6: الأفاتار ثلاثي الأبعاد

## وش نوع الحركة بالضبط (وصف صادق)

- **تهجئة إجرائية بالحروف (procedural fingerspelling)**، وليست تسجيل حركة (motion capture) لشخص أصم، وليست إشارات كلمات كاملة، وليست حركة مولّدة بالذكاء الاصطناعي.
- شكل اليد لكل حرف مأخوذ من **نقاط MediaPipe لصور حقيقية** من داتا سيت ArASL (ملف `public/data/handshapes_ar.json`، 32 حرف بما فيها "ال" و"لا").
- الذراع تتحرك بـ IK بسيط لعظمتين (كتف ومرفق) عشان اليد توصل قدام الصدر، والرسغ والأصابع تلف عشان تطابق اتجاه كل عقلة في الصورة.
- الملف القديم `avatar.fbx` فيه مقطع حركة واحد مسجّل مسبقًا (`playAvatar`)، وما زال مدعومًا لكنه ليس ترجمة لنص.

## اللي تغيّر في هذه المرحلة

| المتطلب في البرومبت | الحالة | التفاصيل |
|---|---|---|
| انتقالات ناعمة | منجز | أول 40% من وقت كل حرف انتقال smoothstep من الوضعية السابقة، والباقي ثبات عشان الحرف يتقرأ. بعد آخر حرف ترجع اليد لوضعية الوقوف بنعومة |
| حرف مكرر (مثل "لل") | منجز | اليد ترتخي 30% نحو الراحة ثم ترجع لنفس الشكل، عشان يبان أنه حرفين |
| المسافة بين الكلمات | منجز | اليد ترتخي 40% نحو الراحة |
| أصابع وذراع وجزء علوي | منجز (سابقًا) | 15 عظمة إصبع + رسغ + مرفق + كتف لليد اليمنى |
| أدوات التشغيل | منجز | إيقاف مؤقت / متابعة / إعادة / سرعة 0.5× و0.75× و1×. الساعة خاصة بالتهجئة فتتوقف فعلًا مع الإيقاف |
| حرف بدون شكل يد | منجز | ما نخترع إشارة: الحرف يظهر باهت ومنقّط في الشريط مع تنبيه، واليد ترتخي مكانه |
| لغة إشارة لكل لغة | منجز | أشكال اليد محفوظة لكل لغة إشارة لحالها (`arsl` و`asl`) وما تختلط |
| تعابير الوجه | منجز بحدود | فقط للسؤال (حين ينتهي النص بـ ؟ أو ?): سؤال بأداة استفهام = حواجب منخفضة، سؤال نعم/لا = حواجب مرفوعة. رمش وابتسامة خفيفة وحركة فم مع الصوت كانت موجودة |
| اللقطة والإضاءة | منجز | لقطة نصف علوية تتكيف مع شكل الإطار (جوال طولي أو شاشة عريضة)، والرأس واليد المتهجية دايمًا فوق شريط الحروف |

## حدود معروفة (لازم تنقال في العرض)

1. **ASL ما لها أشكال يد بعد**: ما فيه ملف `handshapes_en.json`، فإذا اخترت ASL تظهر الكلمة كنص مع تنبيه "ما عندنا أشكال يد لـ ASL بعد". نحتاج صور حروف ASL (مثل داتا سيت ASL Alphabet) ونشغّل `model/handshapes.py` عليها.
2. **تعابير السؤال**: موثّقة كعلامات نحوية في ASL. في لغة الإشارة السعودية نطبقها بنفس الطريقة، لكنها **تحتاج مراجعة من مستخدمين صم سعوديين** قبل ما نعتبرها صحيحة.
3. **حروف ArSL اللي تتحرك** (مثل بعض الحروف اللي فيها حركة) تظهر كشكل ثابت، لأن المصدر صور ثابتة.
4. اليد اليمنى فقط، وما فيه حركة لليد اليسرى أو للجسم أثناء التهجئة.
5. ما قسنا مدى فهم المستخدمين الصم للتهجئة: **Not Measured**.

## الملفات

- `src/components/ui/AvatarViewer.tsx`: محرك التهجئة الجديد (ساعة، انتقالات، تكرار، رجوع للراحة، أحداث `spellControl` و`spellState`، تعابير الحواجب، اللقطة المتكيفة `Framing`).
- `src/components/ui/SpellCaption.tsx`: شريط الحروف + أدوات التشغيل + تنبيه الحروف غير المدعومة (مشترك بين شاشة المساعد وشاشة المحادثة الفورية).
- `src/lib/fingerspell.ts`: `splitLetters` ترجع `{ch, ok}` بدل ما تحذف الحروف غير المدعومة، و`questionType` لنوع السؤال.
- `src/i18n/ar.json` و`en.json`: قسم `avatar`.
- `src/components/screens/CameraScreen.tsx`: إصلاح ارتفاع الأفاتار في الجوال (كان 150px بسبب `flex-1` بدون ارتفاع محدد).

## الأحداث (للمطورين)

```ts
// يبدأ التهجئة
window.dispatchEvent(new CustomEvent("spellText", { detail: { text, signLang, question? } }));
// تحكم
window.dispatchEvent(new CustomEvent("spellControl", { detail: { cmd: "pause" | "resume" | "replay" } }));
window.dispatchEvent(new CustomEvent("spellControl", { detail: { cmd: "speed", value: 0.5 } }));
// الحالة: { status: "playing" | "paused" | "idle", speed, tokens, index, question }
window.addEventListener("spellState", ...);
```
